# MyScoutee Old

**The original MyScoutee UI prototype and the surviving archive of its early development.**

MyScoutee explores a group-based dating concept built around shared priorities
and social interaction. This repository preserves the earlier generation of
the interface and provides context for the current MyScoutee project.

[Archived UI prototype](https://fssrepository.github.io/myscoutee-old/) ·
[Current MyScoutee](https://github.com/fssrepository/myscoutee) ·

## Where it started

The project began in **2016**. Its early development was primarily manual,
with a substantial period of research, experimentation and later refactoring.

| Phase | Background |
| --- | --- |
| Origins | Work on the original MyScoutee concept and system began in 2016. |
| Research and development | Approximately **one and a half years** spent developing and exploring the concept. |
| Later refactoring | Approximately **six months** spent revisiting and restructuring the earlier implementation. |
| Surviving archive | The earlier frontend and supporting materials remain here; the original backend no longer survives as a standalone version. |
| New generation | The work evolved into the current MyScoutee repositories, with AI-assisted development accelerating implementation. |

These durations describe project phases recalled by the creator. Historical
working hours remain unknown, and the archive's Git dates also reflect later
imports of existing work.

---

## From the original project to today's MyScoutee

The current project grew out of the ideas, experience and structure developed
here. According to the creator’s recollection, the earlier backend was cloned
as a starting point. Much of its file content was then removed and rewritten
with AI assistance, accelerating the development of the new generation.
The original backend no longer survives separately, but this was a continuation
from an existing foundation rather than a project begun without one.

- [Current MyScoutee repository](https://github.com/fssrepository/myscoutee).
- [Current UI prototype](https://fssrepository.github.io/myscoutee/).
- [MyScoutee Project](https://github.com/users/fssrepository/projects/2), including delivered work and AI usage estimates.

The original manual work and later AI-assisted tasks are recorded separately.
The [MyScoutee Old Project](https://github.com/users/fssrepository/projects/3)
keeps unknown historical effort blank and identifies recent AI-assisted
repository administration explicitly.
